## Security update

KatlOS 2026.10.3 updates containerd from 2.3.5 to 2.3.7. Upgrade your nodes to
receive the security fixes in [containerd 2.3.6](https://github.com/containerd/containerd/releases/tag/v2.3.6)
and [containerd 2.3.7](https://github.com/containerd/containerd/releases/tag/v2.3.7),
including fixes for denial of service through crafted container images.

This release also updates crun from 1.28 to 1.30.1. Katl builds both runtimes
from pinned upstream sources and installs them as RPMs in the immutable OS
image. Future runtime updates can be released independently of Fedora's package
schedule.

## Upgrade KatlOS

Upgrade `katlctl` before upgrading your nodes. Follow the
[host upgrade procedure](https://github.com/katl-dev/katl/blob/main/docs/operations/upgrade-host.md)
for artifact selection, planning, upgrade, and rollback. Runtime updates are
delivered through the KatlOS node upgrade.

## Known limitations

Host reboot, shutdown, and upgrade can hang while Ceph RBD filesystems remain
mounted. Arrange and verify storage teardown outside Katl before host
maintenance. Ordinary workload drain is not a verified workaround. See the
[host upgrade preconditions](https://github.com/katl-dev/katl/blob/main/docs/operations/upgrade-host.md#preconditions).
