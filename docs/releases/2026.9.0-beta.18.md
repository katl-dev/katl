## Upgrade paths

The beta.18 host upgrade prepares its target generation using the target
release's `katlc` before reboot. This avoids requiring the installed agent to
understand new target configuration fields. The installed agent still checks
the target's basic upgrade receipt and boot artifacts before changing boot
selection.

- From beta.17, use the beta.18 `katlctl` and the normal `katlctl node upgrade`
  command. Plan first and upgrade one node at a time.
- From beta.14, use the one-time [beta.14 bridge procedure](https://github.com/katl-dev/katl/blob/v2026.9.0-beta.18/docs/operations/upgrade-host.md#move-a-beta14-node-across-the-image-metadata-change).
  It uses the beta.14 CLI, an exact beta.18 image copy, and adjacent metadata
  with only `extensionRelease` removed. Verify the copied image against its
  published checksum. Switch to the beta.18 CLI after the node boots beta.18.

Do not use the beta.14 metadata bridge after a failed target preparation or
compatibility check. Preserve the operation output and boot logs if the trial
fails; the previous generation remains the default boot choice. The published
[host upgrade guide](https://github.com/katl-dev/katl/blob/v2026.9.0-beta.18/docs/operations/upgrade-host.md)
describes recovery and kernel flavour selection. These routes do not establish
an upgrade guarantee for every earlier beta.

## Interrupted configuration applies

If the agent restarts before a configuration apply changes the live node or
boot selection, it abandons the incomplete candidate and reports a retryable
failure. If the candidate may have
changed the running node or boot choice, the operation remains locked for
inspection instead of silently discarding state.
After a live apply rolls back successfully, its rejected candidate is marked
abandoned so a corrected apply can proceed.

Live generation promotion now sets the next EFI boot entry to the promoted
generation as well as making it the persistent default. This prevents an
earlier one-shot generation selection from taking precedence at the next
reboot.
